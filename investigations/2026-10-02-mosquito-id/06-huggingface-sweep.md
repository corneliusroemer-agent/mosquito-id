# 06 — Hugging Face sweep: mosquito/vector models and datasets beyond the known set

Driving script: `06-huggingface-sweep/sweep.py` (search+triage) and `06-huggingface-sweep/fetch_cards.py` (card/metadata fetch, 66 repos in 50 s); raw search dumps in `06-huggingface-sweep/models-all.json` / `datasets-all.json`, card copies in `06-huggingface-sweep/cards/`, shortlist digests in `06-huggingface-sweep/shortlist-*.tsv`. All URLs accessed 2026-10-02.

Method: HF API id-search (`/api/models?search=…`, `/api/datasets?search=…`, `full=true`), terms iterated and deduped: mosquito, mosquito detection/classification/identification, culicidae, culico, CulicidaeLab, aedes, culex, anopheles, culiseta, diptera, entomo*, insect, insecta, arthropod, wing, bioscan, biodiversity, inaturalist, species identification, dengue, malaria, vector surveillance, insecticide, wing length, larvae + author sweeps (iloncka, CulicidaeLab, imageomics, bioscan-ml, birder-project, mosquito-alert). ~2,460 model hits / ~465 dataset hits total. HF full-text card search needs auth (401) — this sweep sees only repo ids; anything whose card but not name mentions "mosquito" is invisible to it. Searches with zero model hits: culicidae, CulicidaeLab, entomology, mosquito identification. Dataset searches: culicidae/culex/anopheles/diptera/larvae/wing length all 0. Known set (culico-net-cls/det/segm, bioclip, bioclip-2, bioclip-2.5-vith14) excluded except as variants.

Headline: **the genuinely mosquito-relevant HF landscape outside the known set is small.** The one big find is a dataset (Mosquito Alert 2023 challenge, real European phone photos, exact target taxa), one ecosystem discovery (CulicidaeLab has 46-species raw data + a top-5 model collection), one new independent 41-species classifier, and insect-domain feature extractors from birder-project/BIOSCAN worth testing as embedders.

## Recommended additions to the local test set (for the sibling running models)

1. **mosquito-alert/ai-mosquito-alert-challenge-2023** (10.4 GB, CC-BY-NC-SA) — first priority. Independent, European, phone-photo domain; has Culiseta-genus and japonicus/koreicus labels, i.e. precisely our hard cases. Run every model (Kindwise/BioCLIP/culico-net) against it and measure per-class top-1/top-3.
2. **iloncka/mosquito_data_raw** (5.1 GB, Apache-2.0) — second priority, 45-class European-taxa config: the only public label space deep enough to test *Culiseta annulata vs longiareolata vs morsitans* and *Culex torrentium vs modestus*. Note: albopictus/japonicus/koreicus/pipiens are absent, so it complements rather than replaces #1.
3. **birder-project/vit_b16_ls_franca-bioscan5m** (Apache-2.0, 86M) — as an embedder for kNN retrieval against a small curated European-Culicidae gallery; compare its embeddings against BioCLIP 2.5's on the same crops. The tiny `rdnet_t_ibot-bioscan5m` is the cheap fallback.
4. **Sahil35077/mosquitoscope-convnextv2-tiny** (MIT, single .pth, timm) — 41-species independent vote; cheap to run; distrust its 74% headline (1,228 training images, no provenance).
5. **mahan-ym/bioclip-2-quantized** — int8-ONNX BioCLIP-2 for CPU-only serving; check accuracy delta before trusting.
6. If we host BioCLIP 2.5 as an API: copy the `handler.py` pattern from **skram/bioclip-2.5-vith14-endpoint** rather than writing one from scratch. For the app/API side of mosquitoalert itself, see `05-hosted-apis.md` (sibling report).
7. Optional: culico-net top-5 collection models as a 5-model ensemble on the same 17 classes; **InsectSAM** as backup segmenter.

Nothing else on the hub cleared the bar: after junk removal, every remaining mosquito-named model is 0-download student work with no card, and the insect-adjacent finds (farm pests, LepiNet, fish/butterfly BioCLIP fine-tunes) carry no mosquito labels. The Hub's id-search also has real blind spots (0 hits for "culicidae"/"entomology"), so absence here is weaker evidence than usual — but combined with author sweeps (iloncka, imageomics, bioscan-ml, birder-project, mosquito-alert) the coverage is reasonably complete for repos that matter.
